# Анимации (источник: blender/air_defense.blend, кадры 1–200, 24 fps)

Координаты — в системе OBJ/игры (Y вверх, «вперёд» = −Z). В Blender это (x, −z, y).
Все части экспортированы в положении покоя; рендер только поворачивает/сдвигает их.

## Бук (buk.obj)

| Часть | Движение | Ось / точка | Диапазон |
|---|---|---|---|
| Carriage, Radar, Launcher, Ram*, Missile1–4 | рыскание (yaw) | Y через (0, 0, 0) | 360° |
| Launcher, Missile1–4 | подъём рампы | X через (0, 2.4, 1.4) | 0…45° (вверх = нос к +Y) |
| Radar | раскрытие из сложенного | X через (0, 2.45, −1.4) | 0 (лежит) … 90° (стоит) |
| RamCylinder | следит за проушиной | X через A = (0, 1.45, −0.2) | считается |
| RamRod | поворот как цилиндр + выдвижение вдоль A→B′ | — | считается |

Гидроцилиндр: B = (0, 2.45, −1.4) — проушина на рампе в покое. B′ = B, повёрнутая вместе с рампой.
Угол цилиндра = угол(A→B′) − угол(A→B) в плоскости YZ. Выдвижение штока = |A→B′| − |A→B|.

Порядок: разворот + подъём рампы → радар раскрывается только при рампе > 35° → пуски →
радар складывается → рампа опускается. Ракета n при пуске прячется в модели и появляется сущностью
на направляющей (Missile n, ось ракеты вдоль рампы).

## Тор (tor.obj)

| Часть | Движение | Ось / точка | Диапазон |
|---|---|---|---|
| Turret, SearchRadar, TrackRadar | рыскание | Y через (0, 0, 0) | 360° |
| SearchRadar | постоянное вращение | Y через (0, 0, 1.1) | 1 оборот / 2 с |
| TrackRadar | угол места на цель | X через (0, 2.1, −0.95) | 0…60° |
| Hatch1–4 (задний ряд) | открытие люка назад | X через (x, 2.22, 0.81) | 0…110°, свободный край вверх и назад |
| Hatch5–8 (передний ряд) | открытие люка вперёд | X через (x, 2.22, −0.31) | 0…110°, свободный край вверх и вперёд |

Люк n стоит над ячейкой n: x = −0.54 + 0.36·((n−1) mod 4), z ячейки = 0.6 (задний ряд) или 0.1 (передний).
Люк открывается за ~0.4 с до пуска из своей ячейки и закрывается через ~1 с после.

Пуск (холодный, вертикальный): ракета из ячейки VLS (−0.54, 2.0, 0.6) вылетает вверх катапультой
(~2 блока за 0.35 с, с торможением), за 0.3 с газодинамикой доворачивает на цель,
затем включается двигатель и ракета разгоняется. Модель ракеты: часть TorMissile, нос вдоль −Z.
