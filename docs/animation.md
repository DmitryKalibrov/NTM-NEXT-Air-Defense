# Анимации (источник: blender/air_defense.blend, кадры 1–200, 24 fps)

Координаты — в системе OBJ/игры (Y вверх, «вперёд» = −Z). В Blender это (x, −z, y).
Все части экспортированы в положении покоя; рендер только поворачивает/сдвигает их.

## Бук (buk.obj) — пусковая 9А310 по чертежу, исходник blender/buk_m1.blend

Основание 4×4 высотой 0,6 с разъёмом питания. Корпус 3,0 × 5,5 + обтекатель РЛС в носу (до z −3.72),
кормовая «голова» с шарниром рампы, ракеты 9М38 длиной 5,55.

| Часть | Движение | Ось / точка | Диапазон |
|---|---|---|---|
| Carriage, Radar, Launcher, Ram*, Missile1–4 | рыскание (yaw) | Y через (0, 0, 0) | 360° |
| Radar | неподвижен (обтекатель 9С35 в носу) | — | — |
| Launcher (с кормовой головой), Missile1–4 | подъём рампы | X через (0, 2.05, 2.6) | 0…40° |
| RamCylinder (2 шт., x = ±1.25) | следит за проушиной | X через A = (0, 1.63, 0.6) | считается |
| RamRod | поворот как цилиндр + выдвижение вдоль A→B′ | — | считается |

Гидроцилиндр: B = (0, 2.45, 1.2) — проушина на рампе в покое. B′ = B, повёрнутая вместе с рампой.
Направляющие x = ±0.375, ±1.125; центр ракеты в покое (y 3.15, z −0.275).
Порядок: разворот + подъём рампы, РЛС «прогревается» (radar 0→1) → пуски.

## Тор (tor.obj) — боевой модуль в масштабе «Тор-М2КМ», исходник blender/tor_m2km.blend

Основание 4×4 (как у Бука), вращающийся модуль 5,9 × 3,1, высота пускового модуля 3,0, обзорная РЛС до ~4,7.

| Часть | Движение | Ось / точка | Диапазон |
|---|---|---|---|
| Turret, SearchRadar, TrackRadar, Hatch1–8 | рыскание | Y через (0, 0, 0) | 360° |
| SearchRadar | постоянное вращение | Y через (0, 0, 2.25) | 1 оборот / 2 с |
| TrackRadar | угол места на цель | X через (0, 1.85, −2.5) | 0…60° |
| Hatch1–4 (задний ряд) | открытие люка назад | X через (x, 3.33, 0.78) | 0…110° |
| Hatch5–8 (передний ряд) | открытие люка вперёд | X через (x, 3.33, −0.78) | 0…110° |

Ячейка n: x = −0.72 + 0.48·((n−1) mod 4), z = 0.415 (задний ряд) или −0.415 (передний), пуск с y = 3.4. Платформа высотой 0,6; питание только через разъём: ячейка модели x −1…0, z 1…2, кабель сзади (+Z).
Ракета TorMissile (9М331): длина 2,9, нос вдоль −Z, центр в начале координат.

## Панцирь (pantsir.obj) — боевой модуль «Панцирь-С1», исходник blender/pantsir_s1.blend

Основание 4×4 с разъёмом питания, корпус 2,3 × 4,45, два боковых боевых блока (по 6 ТПК 57Э6 и спаренной 20-мм пушке).

| Часть | Движение | Ось / точка | Диапазон |
|---|---|---|---|
| Turret и всё на нём | рыскание | Y через (0, 0, 0) | 360° |
| WeaponL, WeaponR, Cap1–12 | угол места, каждый блок на своей цапфе (x = ±1.32) | X через (0, 1.65, −0.2) | −5…80° |
| TrackRadar | угол места, своя ось | X через (0, 1.45, −1.15) | как блоки |
| SearchRadar | складывание назад над кормой | X через (0, 2.85, 1.9) | 90° (сложена) … 0 (стоит) |
| SearchRadar | вращение, только когда стоит | Y через (0, 0, 1.9) | 1 оборот / 2 с |

ТПК n (1…12): сначала левый пакет (x −1.55), потом правый (+1.55); внутри пакета ряды y 1.82 / 2.1, колонны x ±0.27 и 0;
срез ТПК z = −1.7. Крышка Cap n видна, пока ТПК заряжен. Стволы пушек: x = ±1.55 ± 0.1, y 1.3, дульный срез z −3.1.
Ракета 57Э6 в полёте: PantsirStage (ускоритель, центр на 0,9 позади центра ракеты) + PantsirDart.

## Сборочный цех (defense_assembler.obj) — исходник blender/defense_assembler.blend

Закрытый бетонный цех 9×9×7, ворота 6,2 × 5,7 на обоих торцах (±Z). Части крана и рук экспортированы в покое.

| Часть | Движение | Ось / точка |
|---|---|---|
| Bridge | вдоль Z (парковка у задних ворот z = 3.3) | — |
| Trolley | вдоль X | — |
| Hook | кончик траверсы в (0, 0, 0); ставится в точку подвеса | — |
| Cable | единичной длины от (0, 0) вверх; масштаб по Y до барабана y = 6.65 | — |
| ArmLower / ArmUpper / ArmHead | поворот вокруг Z, плюс = к центру | плечо (3.5, 2.4), локоть (3.5, 4.3), кисть (2.0, 4.3) |
| ArmSpike | сдвиг по Y в системе головы | angles[3] × 0.5 |

Рука A стоит в z = −0.9, рука B — та же, повёрнутая на 180° вокруг Y. Углы — `arms[i].getPositions` сборочной машины NTM.
Кран: на каждый узел техники (первый стоит сразу) приходится равная доля прогресса рецепта: узел висит на крюке
у задних ворот → едет к месту (0.05–0.45) → опускается (0.45–0.62) → крюк поднимается, кран уходит назад (0.65–1).
Крюк цепляет узел за верх его габарита (`boundsOfParts`).
